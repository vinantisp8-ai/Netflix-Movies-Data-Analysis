Netflix Movies Data Analysis 🎬
📌 Project Overview
This project focuses on analyzing Netflix movie data using Python to understand movie ratings, release years, content trends, and other patterns within the dataset.
The analysis includes data cleaning, exploratory data analysis (EDA), and multiple visualizations to extract meaningful insights from the dataset.
🛠️ Tools & Technologies
Python
Pandas
Matplotlib
Seaborn
Jupyter Notebook
🔍 Key Analysis
Movie release year analysis
Movie rating distribution
Movies added to Netflix over time
Rating categories
Top release years
Cast-wise movie appearance analysis
Rating trends across release years
Overall movie content analysis
📊 Visualizations
Different chart types were used to present the analysis clearly, including:
Bar charts
Pie/Donut charts
Scatter plots
Distribution plots
Trend charts
📁 Dataset
The project uses a Netflix movie dataset containing information such as:
Show ID
Title
Cast
Country
Date Added
Release Year
Rating
Duration
🎯 Objective
The objective of this project is to explore Netflix movie data, identify useful patterns and trends, and present the findings through clear and informative visualizations.
