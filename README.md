 # 🎬 Netflix Movies Data Analysis
 # 📌 Project Overview
 This project presents an Exploratory Data Analysis (EDA) of a Netflix Movies dataset using Python. The analysis focuses on movie popularity, ratings, budget, revenue, profit, genres, countries, languages, directors, and release trends.
The objective is to discover meaningful patterns and relationships in the dataset through data cleaning, statistical analysis, and data visualization.

# 🎯 Objectives
1.Analyze movie popularity and ratings.
2.Explore the relationship between budget, revenue, popularity, and ratings.
3.Identify top-performing genres.
4.Analyze movie prodution across countries.
5.Compare country-wise budget, revenue, and profit.
6.Explore movie distribution across Languages.
7.Identify directors with strong average ratings and profitability.
8.Analyze movie release trends across leading countries.
9.Generate meaningful insights  using visualizations.
